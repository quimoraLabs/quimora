# Git Workflow & AI Safety Rules

## ⛔ STRICT RULE: NEVER EXECUTE `git push`

* **No Automated Push**: The AI assistant MUST NEVER execute `git push` or push code to remote repositories under any circumstances.
* **Local Operations Only**: The AI may stage changes (`git add`) or create local commits (`git commit`) ONLY when explicitly instructed by the user.
* **User Manual Execution**: Pushing code to remote (`git push origin main`) MUST ALWAYS be performed manually by the human developer/user.
