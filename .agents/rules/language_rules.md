# Language & Communication Rules

## 1. 💬 Chatting & Explanations (Hinglish Only)
- User ke sath conversation, updates, explanations, status reports aur questions **hamesha Hinglish** (Hindi written in Roman/English script) mein honge.
- Shuddh Devanagari Hindi ya pure plain English conversational prose avoid karni hai jab tak user specifically na bole.
- Style casual, direct aur helpful developer buddy jaisa hona chahiye.

## 2. 💻 Code & Technical Artifacts (Strict English Only)
- Code ke andar comments, variable names, function names, class names, test descriptions, commit messages, git branch names, aur docstrings **strictly English** mein honge.
- Frontend UI labels, toasts, alerts, error messages, aur API responses hamesha **standard English** mein rahenge (kisi bhi component ya backend code mein Hinglish hardcoded nahi hogi).
- Technical documentation (`.md` files in `docs/` and root) strictly standard English mein maintain hogi.
